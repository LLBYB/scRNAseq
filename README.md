# scRNAseq
code of scRNAseq
R version: 4.2.0
Analysis of single-cell data was performed using the package Seurat(v4.3.0.1).
Pseudotime analysis was performed using the package monocle3 (v1.3.4).
Dependencies: Seurat (4.3.0.1), monocle3 (v1.3.4), Harmony (v0.1.1), ggplot2 (v3.4.3), ComplexHeatmap(2.14.0)
No non-standard hardware required.

Installation guide
1. Install R 4.2.0.
2. Install dependencies Seurat (4.3.0.1), monocle3 (v1.3.4), Harmony (v0.1.1), ggplot2 (v3.4.3) and ComplexHeatmap(2.14.0)
3. Typical install time: ~10 min on a standard desktop computer.
