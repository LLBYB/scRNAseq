# scRNAseq
code of scRNAseq
R version: 4.2.0
Analysis of single-cell data was performed using the package Seurat(v4.3.0.1).
Pseudotime analysis was performed using the package monocle3 (v1.3.4).
Dependencies: Seurat (4.3.0.1), monocle3 (v1.3.4), Harmony (v0.1.1), ggplot2 (v3.4.3), ComplexHeatmap(v2.14.0), circlize(v0.4.15)
No non-standard hardware required.

Installation guide:
Install R 4.2.0.
Install dependencies Seurat (4.3.0.1), monocle3 (v1.3.4), Harmony (v0.1.1), ggplot2 (v3.4.3), ComplexHeatmap(v2.14.0) and circlize(v0.4.15)
Typical install time: ~10 min on a standard desktop computer.

Tested environment:  R 4.2.0
Input: 3002/
Expected output: UMAP and pseudotime plot
Expected runtime: 30 min
